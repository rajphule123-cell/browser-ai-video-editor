## Key Features

- **Client-Side Rendering**: Hardware-accelerated rendering and exporting using WebCodecs and PixiJS v8 via `@openvideo/engine-pixi`.
- **Multi-Track Timeline**: Layered editing for video, audio, and images with drag-and-drop, splitting, trimming, and snapping.
- **Interactive Canvas**: Real-time viewport preview supporting drag, resize, rotate, and layer re-ordering.
- **Asset Management**: Local and cloud storage (e.g., Cloudflare R2, AWS S3) for media uploads.
- **Effects & Transitions**: Custom shader-based transitions and effects applied between clips.
- **Local Exporting**: Direct timeline rendering into MP4 files using browser APIs with zero server rendering costs.
- **Modern UI/UX**: Dark-mode interface built with Tailwind CSS v4, Radix UI, and Framer Motion.

## Getting Started

### 1. Installation

Install the frontend and backend dependencies from the project directory:

```bash
npm install
```

### 2. Environment Setup

Create separate frontend and backend environment files:

```bash
cp .env.sample .env.local
cp backend/.env.sample backend/.env
```

| Variable | Description |
| :--- | :--- |
| `NEXT_PUBLIC_API_URL` | Backend URL used by the frontend (default: `http://localhost:4000`). |
| `BACKEND_PORT` | Port used by the standalone API backend (default: `4000`). |
| `FRONTEND_ORIGIN` | Comma-separated frontend origins allowed to call the backend (defaults to ports `3000` and `3001`). |
| `R2_*` | Cloudflare R2 credentials and public bucket domain; required for uploads. |
| `DEEPGRAM_API_KEY` | API key for audio and video transcription. |
| `PEXELS_API_KEY` | API key for the stock media library. |

API keys cannot be generated by the app. Create provider accounts and use their free-tier or trial credentials: [Cloudflare R2](https://dash.cloudflare.com/), [Pexels API](https://www.pexels.com/api/), and [Deepgram](https://console.deepgram.com/). Only the Cloudflare R2 values are needed for uploads; Pexels and Deepgram are optional. Free-tier usage limits may apply. Keep `backend/.env` private and never commit real keys.

### 3. Run the Frontend and Backend

Run both services together:

```bash
npm run dev
```

The frontend runs at [http://localhost:3000](http://localhost:3000); the API backend runs at [http://localhost:4000](http://localhost:4000).

To run either service separately, use two terminals:

```bash
npm run dev:frontend
npm run dev:backend
```

The backend exposes `/api/health`, `/api/pexels`, `/api/audio/music`, `/api/audio/sfx`, `/api/transcribe`, `/api/uploads`, and `/api/uploads/presign`.
